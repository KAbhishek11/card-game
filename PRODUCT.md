# Product
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
delegated: React and Node multiplayer server, approved by user. Same-Wi-Fi play confirmed; public hosting deferred.
## Users
Friends who are experienced social-deduction players, together with first-time players, using desktop and mobile browsers.
## Product Purpose
A functioning private-room multiplayer game with the gameplay of The Resistance: Avalon, familiar Avalon role names, and Indian-inspired art.
## Operating Context
A host creates a room, chooses one of three art themes, and invites friends. Friends enter names, join, and privately receive characters before play.
## Capabilities and Constraints
Beginner-friendly rules and game flow. Preserve the source game's mechanics. Keep Gupt Sabha branding and Indian-inspired artwork. The user explicitly chose the familiar Avalon role names to reduce learning effort. Public hosting remains undecided.
## Brand Commitments
The latest three attached references supersede the original Figma moodboard for card themes, in attachment order: Katha (black/bone flat silhouettes), Rang (saturated contemporary Indian pop portraits), Vana (teal/green illustrated action and luminous spirit contours). The user explicitly requested a more distinctive game interface after the first functioning build.
## Product Principles
Private information stays private. Explain each action when needed. Make room joining simple. Keep rules consistent across themes and screen sizes.
## Open Decisions
Working name: Gupt Sabha. Roles use Merlin, Assassin, Percival, Morgana, Mordred, Oberon, Loyal Servant of Arthur, and Minion of Mordred. User chose building directly in code. Public hosting deferred; same-Wi-Fi play is the current scope.

## Material and Feedback
User requested skeuomorphic buttons, game-specific icons, sound effects, and reflective holographic cards. Preserve familiar role names and the three reference-led art themes. Use short gesture-initiated audio with persistent mute; keep secret-role cues identical.

## Game Presentation
The user requested further enhancement inspired by real games. The UI now uses an original illustrated council chamber, a room menu beside a three-card fan, compact theme selection, and explicit public expedition scores. Hearthstone and Runeterra informed environmental framing and state presentation; original artwork and existing mechanics remain.

## Merlin Artwork
Merlin must be depicted as an adult male in all three themes, as requested by the user. Dedicated katha-merlin.png, rang-merlin.png, and vana-merlin.png portraits override atlas slot zero; other roles and card backs retain their existing atlas art.

## Revised deck artwork — September 2026

The user requested more visual distance from the original references. Active assets are now public/art/katha-v2.png, public/art/rang-v2.png, and public/art/vana-v2.png. Katha uses engraved charcoal and bone with copper details and stepped architecture; Rang uses warm screen-print textures and asymmetrical architectural colour fields; Vana uses layered moonlit forest painting with silver botanical borders. Poses, costumes, and common backs were revised. The backs use a compass seal, ribbon knot, and mirrored banyan trees respectively, replacing the eye motifs.

All roles, including adult male Merlin, now come from the same 3×3 atlas. The standalone Merlin overrides are no longer consumed. Original files remain available for rollback. Role order, theme IDs, game mechanics, and public/private information remain unchanged. Built-in imagegen prompts are saved in docs/redesign/theme-v2/PROMPTS.md.
